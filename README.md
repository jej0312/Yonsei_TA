# DM_TA
This repository contains the materials used for lab sessions while serving as a teaching assistant for **Data Mining Theory and Practice** in the **Spring 2022 semester**.

- The [Data folder](https://github.com/jej0312/Yonsei_TA/tree/main/data) contains the datasets used in the lab sessions.
- The lab sessions are organized as follows:
  1. [Data Preprocessing](https://github.com/jej0312/Yonsei_TA/blob/main/DM/1_Data_preprocessing.ipynb)
  2. [Principal Component Analysis, Factor Analysis](https://github.com/jej0312/Yonsei_TA/blob/main/DM/2_PCA_FA.ipynb)
  3. [Clustering](https://github.com/jej0312/Yonsei_TA/blob/main/DM/3_Clustering.ipynb)
  4. [Case-Based Reasoning, Association Rules](https://github.com/jej0312/Yonsei_TA/blob/main/DM/4_CBR(knn)_AR.ipynb)
  5. [Social Network Analysis](https://github.com/jej0312/Yonsei_TA/blob/main/DM/5_SNA.ipynb)
  6. [Logistic Regression, Model Assessment](https://github.com/jej0312/Yonsei_TA/blob/main/DM/6_LogisticRegression.ipynb)
  7. [Decision Tree](https://github.com/jej0312/Yonsei_TA/blob/main/DM/7_DecisionTree(CART).ipynb)
  8. [Neural Networks](https://github.com/jej0312/Yonsei_TA/blob/main/DM/8_ANN_SOM.ipynb)
  9. Ensemble Methods (Bagging, Arching)
- The lab materials were developed based on the [Spring 2021 DM reference materials](https://github.com/HyunwooWoo/DataMining).

# QE_TA

  3. [QFD & AHP (Python)](https://github.com/jej0312/Yonsei_TA/blob/main/QE/3_QFD%2BAHP.ipynb)
  4. Conjoint Analysis
     - [R](https://github.com/jej0312/Yonsei_TA/blob/main/QE/4.%20Conjoint%20Analysis.R)
     - [Python](https://github.com/jej0312/Yonsei_TA/blob/main/QE/4_Conjoint%20Analysis.ipynb)
  5. [Taguchi Design](https://github.com/jej0312/Yonsei_TA/blob/main/QE/5_Taguchi_Design.ipynb)
  6. [Statistical Process Control (SPC)](https://github.com/jej0312/Yonsei_TA/blob/main/QE/6.%20SPC.ipynb)
